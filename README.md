# 网电空间对抗性攻防算法验证平台

无线电调制识别的对抗攻击与恶意样本检测演示。前端 Vue 3，后端 Flask + PyTorch。

- 使用说明、攻击/检测含义、信号图读法：见 [项目说明.md](项目说明.md)
- 本机启动步骤：见 [启动方法.md](启动方法.md)

本仓库包含源代码、文档、结果表格、小数据集（如 `radio1/2/3.pkl` 与 300–5000 条抽样子集），以及推理用模型权重（`radioAdv/model/`）。完整 `RML2016.10a_dict.pkl`、Python 虚拟环境、`node_modules` 和演示视频不纳入版本库，需在本地按启动文档准备。
